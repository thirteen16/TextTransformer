# 双击按键实现对应使用功能

Windows 文本转换托盘程序。双击 `TextTransformer.exe` 即可运行，无需安装 AutoHotkey。快捷键、拼音恢复和程序图标均已集成到 EXE。

图标采用橙色底、白色 T 和浅黄色箭头，提供多个尺寸以适配托盘显示。程序窗口仅显示四项双击快捷键及对应功能。

## 快捷键

所有快捷键均不会自动全选输入框或文档。有选区时优先处理选区；没有选区时，CapsLock 和右 Shift 只处理光标前连续的英文字母和英文半角符号，遇到中文、数字、空格、制表符或换行停止。左 Shift 优先提取光标前当前行中的成对引号或成对空格里的内容；没有这种分隔时，只对光标前连续字母、数字和英文符号查词。左 Alt 只处理光标前连续拼音字母。无法确认转换选区时会停止并提示，不会自动扩大为全文。此规则同样适用于 Markdown、Word 和普通输入框。

| 快捷键        | 功能                                                                     | 处理范围                                           |
| ------------- | ------------------------------------------------------------------------ | -------------------------------------------------- |
| 双击 CapsLock | 英文字母全大写；已全大写时转为全小写                                     | 有选区时处理选区，否则处理光标前连续英文字母和符号 |
| 双击左 Shift  | 提取引号或空格分隔的中间内容，保留数字和符号；无中间内容时仅保留英文字母 | 有选区时处理选区，否则按当前行分隔内容或末尾词查找 |
| 双击右 Shift  | 句首大写，其余英文字母小写，同时将中文标点转为英文标点                   | 有选区时处理选区，否则处理光标前连续英文字母和符号 |
| 双击左 Alt    | 把误输的拼音字母重新打入输入法，保留候选框供你选字                       | 有选区时只恢复选区，否则只恢复光标前连续的拼音字母 |

双击指快速按下并松开同一个键两次，每次按住不超过 250 毫秒，两次间隔不超过 400 毫秒。Alt+Tab 等组合键不会触发拼音恢复。启用快捷键时，单独左 Alt 的菜单激活行为会被抑制；右 Alt 不受此功能影响。

混合文本无需整段选中：例如 `中文 hello-world，后文`，把光标放在 `hello-world` 末尾（中文逗号前），双击 CapsLock 得到 `中文 HELLO-WORLD，后文`，双击左 Shift 得到 `中文 helloworld，后文`。CapsLock 若要处理含空格或数字的整段文字，请先手动选择。

左 Shift 自动提取时，把光标放在当前行待处理内容末尾。例如 `dhus idud ss` → `idud`、`前面 “thirteen16/vehicle-control-APP” 后面` → `thirteen16/vehicle-control-APP`；这些情况下会用提取结果替换当前行行首到光标之间的文字。无分隔时，例如 `中文 abc-123` 的光标在末尾，只将末尾 `abc-123` 变为 `abc`，保留前面的 `中文 `。不跨换行或制表符，光标后面的文字不参与处理。自动定位最多读取光标前 1024 字符，超长内容请手动选择；编辑器无法可靠读取当前行时，也请先手动选择。

双击右 Shift 优先处理已选中的文字；没有选区时，请将光标放在待转换内容末尾。程序优先一次读取光标前的文字，计算连续英文字母及英文半角符号的范围：原生 Windows 输入框直接设置选区，其他支持文本接口的编辑器按词或按准确字符数批量选取，最后复制核对一次。接口不完整时才逐字符查找边界。遇到空格、中文、数字、换行等字符时停止，再执行句首大写。例如在 `open` 末尾触发会得到 `Open`，在 `双击右 alt` 末尾触发会得到 `双击右 Alt`。无选区时不全选文档，也不使用 Typora 专用快捷键。最多自动选取 1024 字符，超过该范围请手动选择。已经符合句首大小写规则的文字会直接结束处理。

该方式需要目标编辑器支持标准的 Shift+方向键、Ctrl+C 和 Ctrl+V。选区读取或按键处理不标准的应用仍可能需要手动选中文字。剪贴板恢复会延迟重试；特殊格式无法持久保存时，会先尝试保留全部格式，再回退到原文字内容。其他程序将剪贴板更改为不同内容后，不会用旧备份覆盖它。能读取输入框文字时，会等待替换生效再恢复剪贴板；未能确认替换时，转换结果留在剪贴板供手动粘贴。

左 Shift 优先提取第一对完整英文或中文引号中的所有字符。如果没有成对引号，但包含至少两个普通空格，则保留第一个和最后一个空格之间的所有字符，包括内部数字、符号、中文和空格。首尾空格也作为分隔符。例如 `dhus idud ss` → `idud`，`前面 i-dud!123 后面` → `i-dud!123`，`abc-123` → `abc`。除此之外，所有情况仅保留英文字母 A–Z、a–z。

对于 `To confirm, type "thirteen16/vehicle-control-APP" in the box below`，会提取 `thirteen16/vehicle-control-APP`，保留大小写、数字、斜杠和连字符。不再对没有引号或成对空格的仓库名作特殊处理。

在只读网页中选中提示文字后双击左 Shift，结果会留在剪贴板，可直接粘贴到确认框；在可编辑输入框中使用时，替换选中的文字。

## 恢复误输的拼音

选择微软拼音，关闭 CapsLock。在聊天或其他可编辑输入框中，拼音误变成英文字母后，**保持光标在字母末尾，直接双击左 Alt**。

例如先输入 `这句话，English!`，随后误输 `nihaoshijie`。双击左 Alt 后，前面的中文、英文和符号保留，末尾的拼音重新进入候选状态，供你选择“你好世界”。程序不发送空格或 Enter，不会自动选字或发送聊天消息。

选中了拼音时，同样双击左 Alt，只恢复选中的部分；这一方式也可处理较早输入或粘贴的拼音。支持全拼、双拼字母和英文单引号分隔符（如 `xi'an`），每次最多 64 个字符。选中的大写字母会以小写重新输入。

### 自动恢复的范围

程序在触发时读取光标前的实际文本，只识别紧挨着光标的连续字母和英文单引号；中文、空格、标点、数字及换行作为分隔。自动恢复不再要求键盘历史记录，因此也能处理程序启动前输入或粘贴的拼音。请把光标放在待恢复字母末尾；光标后面的内容不会参与恢复。

为兼容 Codex 等浏览器输入框，程序用 Shift+左方向键选中末尾字母，再临时复制并核对实际选中文字，不依赖浏览器返回的选区坐标。核对不一致会停止，不替换文字。

**已有英文和误输拼音如果连续紧挨着、没有任何分隔，程序无法判断它们的语义分界。**例如连续输入 `hellonihao`，整个连续字母段会作为自动恢复范围；若要保留 `hello`，请选中 `nihao` 后恢复。

### 输入法和输入框兼容性

程序会尝试把微软拼音切回中文模式。输入法状态无法读写时会提示并停止；可以先手动切到“中”，必要时在微软拼音设置 → 常规 → 兼容性中启用“使用以前版本的微软拼音输入法”后重试。

输入法切换和文本接口初始化可能有延迟，程序会在一次双击内短暂等待并重试；剪贴板被临时占用、选区复制尚未更新时也会进行有限重试。仍然失败才显示提醒。切换输入框或产生新的键盘、鼠标输入会立即取消；开始重新打入拼音后，不会重试整段输入，以免重复文字。

拼音恢复支持 Windows UI Automation 文本选区接口、原生 Edit / RichEdit，以及欧陆词典这类 Qt 界面中提供可编辑 ValuePattern 的输入框。Qt 输入框没有 TextPattern 时，通过快捷键复制实际选区；没有选区时临时选择光标前的内容，核对输入框文字后，只恢复末尾拼音。部分自绘输入框或特殊编辑器仍可能不支持，会提示并停止。管理员权限运行的目标应用可能需要同权限运行本程序。

拼音恢复会临时使用剪贴板核对选区，结束后恢复原剪贴板，不处理输入框全文。恢复过程中请不要打字、点击或切换窗口。首次请在记事本试用；如果结果不符，先停止输入，再使用目标应用的撤销功能。

## 托盘与开机自启

右键托盘图标可打开使用说明、勾选开机自启、启用或停用快捷键，以及退出程序。关闭说明窗口后，程序继续在托盘运行。开机启动时只显示托盘图标。

## 构建与检查

在 Windows PowerShell 中运行：

```powershell
.\build.ps1
```

需要 Windows 的 .NET Framework 4.x 编译器，以及框架中的 UI Automation 程序集。生成的 `TextTransformer.exe` 可单独使用或作为 GitHub Release 附件发布。

指定其他输出位置（目录需已存在）：

```powershell
.\build.ps1 -OutputPath "$PWD\TextTransformer-test.exe"
```

运行内置检查（不启动托盘或全局监听）：

```powershell
$check = Start-Process .\TextTransformer.exe -ArgumentList '--self-test' -Wait -PassThru
$check.ExitCode
```

退出码 0 表示检查通过。检查覆盖原有文本转换、双击手势、组合键排除、拼音字符范围、输入边界、长度保护及原生按键结构。实际微软拼音候选框、聊天软件输入框和物理按键兼容性仍需在目标应用中试用。
